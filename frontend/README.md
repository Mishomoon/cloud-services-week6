# Cloud Services Week 5

This repository contains my Cloud Services Week 5 project.

The project extends my Week 4 containerized application on CSC Rahti by adding a Redis cache.

The application includes:

- Nginx frontend
- Flask backend
- MySQL database
- Redis cache
- Kubernetes/OpenShift Deployments and Services

The `index.html` file contains my Week 5 documentation, including Part A questions and Part B hands-on work.
